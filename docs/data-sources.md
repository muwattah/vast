# Data sources

## Supported
- User CSV/JSON import
- Manual API create
- Demo seed (DEMO only)

## Not supported
- Immoweb/Zimmo/Immovlan live scrape (ToS)
- Login-walled portals
- CAPTCHA bypass

## Open data to investigate
- Geopunt/AGIV, VEKA EPC, Biddit (official only), Statbel aggregates, CRAB
Until verified: NOT SUPPORTED.

Rules: every observed price needs source + observed_at; DEMO always labelled; ARV without comps = insufficient data.
